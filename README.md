# Async Payment Processing

Асинхронный сервис обработки платежей на FastAPI, PostgreSQL и RabbitMQ.

Проект реализуется как тестовое задание с акцентом на надежность асинхронной обработки:
Transactional Outbox, идемпотентность, retry, DLQ, webhook delivery и reconciliation.

Подробная документация по архитектуре и запуску будет добавляться по мере реализации.
